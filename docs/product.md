# Agreed first release

1. Students upload a PDF résumé. Matching runs locally, without an AI backend.
   Optional AI/MCP connections are a later feature.
2. Show `Filters: …` from the current WaterlooWorks search. Search scans all
   pages of those results, retaining the selected filters.
3. Every job has fit and interview scores out of 100. Interview scores are
   relative estimates, not percentages. Sort descending by interview score.
4. Search creates or reuses the actual WaterlooWorks folder `coopcupid`.
   Students can save/remove individual jobs, bulk-save scores strictly above a
   cutoff, or opt into automatic saving after each completed search. Jobs saved
   directly on the board also appear in the folder view. Automatic saving is
   off by default and does not run after a stopped or failed search.
5. Auto apply processes every eligible queued folder job, regardless of score.
   Before starting, show the selected résumé and number of jobs. Show progress
   and a Stop button.
6. Use the uploaded résumé in a custom application package and preserve existing
   required transcript/work-history selections. Skip cover letters, additional
   questions, additional required documents, or external applications.
7. Application tracking and public distribution/publishing are separate work.
   Support other students without hardcoded student, employer, document,
   posting, or session identifiers.
